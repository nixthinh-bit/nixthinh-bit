我是 Thinh，一位来自越南的客户成功经理（Customer Success Manager）。

我服务过从中小企业到大型企业、横跨多个行业的合作伙伴与客户，其中始终贯穿着一个信念：客户成功经理
的工作不是推动功能使用率，而是把产品理解得足够深，从而交付每一位客户真正为之付费的那个具体成果。
**价值存在于功能之外。**

这份工作正在改变。在 AI 时代，会用工具不再是优势，而 AI 正在飞快地抹平这种优势。真正的优势在于人
的判断力：判断哪个成果才重要，再指挥 AI 去把它执行出来。**以人为主导，让 AI 辅助——而不是反过来。**

这里就是我分享这一切的地方——我在学的、我热爱的、我做的，以及我想在这段旅程中不断趋近的思维方式。

### 🛠️ 我正在做的项目

**Lark / 飞书**
- **[lark-base-architect](https://github.com/nixthinh-bit/lark-base-architect)** — 一个 Claude
  Code 技能：把一句大白话的业务需求变成可用的 Lark（飞书）多维表格：访谈 → 框架 → ER 图 → 搭建 →
  使用文档 + 自动化建议。英越双语。
- **[lark-anyBase-report](https://github.com/nixthinh-bit/lark-anyBase-report)** — 一个 Claude
  Code 技能：读取任意 Lark（飞书）多维表格并生成洞察报告，先访谈：询问你的 KPI 与时间范围，映射到真实
  结构，草稿待批，再以 Lark 文档或消息交付。英越双语。
- **[lark-cli-onboarding](https://github.com/nixthinh-bit/lark-cli-onboarding)** — 一个链接、一
  条命令，就能在 Claude Code 里跑起 `lark-cli` + 技能 + 令牌自动刷新，让任何人都能从终端操作 Lark。
- **[lark-bridge-onboarding](https://github.com/nixthinh-bit/lark-bridge-onboarding)** — 面向
  零代码用户的接入层，把飞书/Lark 机器人对接到本地 Claude Code 或 Codex CLI：扫码即可，支持流式卡
  片、按会话隔离、多工作区。

**Customer Success（客户成功）**
